# WeChat Layout Assistant · 公众号排版助手

把参考图片和活动内容，转化为有艺术表达、适合手机阅读、能够实际制作的公众号推送方案。

**参考与内容 → 排版预览 → 模块底图 prompt → 完整文案与落位指导。**

这是一套给 AI 助手使用的 skill，不是公众号编辑器，也不是图像生成服务。图像生成、文字排版和文件导出由使用它的宿主工具完成。

## 能做什么

- 分析参考的材质、构图、标题组织与滑动节奏，而不只提取颜色关键词。
- 先制作可供调整的预览：手机首屏、全文分段、正文细节和所需封面。
- 提供一段完整可复制的生图 prompt，用“继续第N张”生成独立模块。
- 提供全部文案、换行、字号、行距、位置与图文关系。
- 区分素材完整和背景连续，明确模块上下边界的拼接方式。
- 按需设计2.35:1横版与1:1方形封面；用户指定比例优先。
- 已有成稿时直接组合原图展示，避免每次重画导致内容与版式漂移。

不保证生图工具精确输出任意尺寸、无误文字或天然无缝边界。实际文件仍需检查；小字使用真实字体，二维码使用真实文件。

## 安装

下载或克隆此仓库，将包含 `SKILL.md`、`references/`、`agents/` 的目录命名为 `wechat-layout-assistant`，放到宿主支持的技能目录。Codex 用户可将它放到自己的 `~/.codex/skills/` 下；自定义配置目录的用户使用对应位置。

安装后的结构应为：

```text
skills/
└── wechat-layout-assistant/
    ├── SKILL.md
    ├── agents/openai.yaml
    └── references/
```

避免额外嵌套成 `wechat-layout-assistant/wechat-layout-assistant/SKILL.md`。其他支持 Markdown 技能的助手可按其安装方式加载；本项目没有内置图像 API、密钥或外部付费依赖。`agents/openai.yaml` 是可选的 Codex 展示元数据。

## 开始使用

上传参考图片后发送：

```text
使用 $wechat-layout-assistant。
主题：潮汐来信 / Letters from the Tide
时间：6月21日 18:30
地点：海风礼堂
板块：引入概念—邀请参加—报名信息
报名：一个二维码，稍后提供
风格：蓝白纸质拼贴，标题错落，正文清楚，模块之间自然衔接。
先给我排版预览，包括2.35:1横版和1:1方形封面。
```

以上为虚构示例，不是默认活动事实。还有几种用法：

```text
只给我一段可复制的模块生图 prompt，以及全部文案与逐块排版指导。
```

```text
这三张是已经完成的正文。保留原图，制作浅色展示板，包含手机首屏、
全文顺序、正文放大细节，并独立设计横版和方形封面。
```

```text
第02块下边缘还有地图与浪花被切断。保留内部构图，修正02出口与03入口，
明确全宽接口色和过渡归属，不要只强调主体完整。
```

## 输出与制作分工

| 阶段 | 交付 | 用途 |
|---|---|---|
| 预览 | 实际可查看的图片或文件 | 调整风格、内容密度、阅读节奏和封面 |
| 核心交付A | 完整模块生图 prompt | 制作插画、装饰、容器和基础艺术字 |
| 核心交付B | 全部文案与对应排版指导 | 在编辑器中用真实字体添加信息 |
| 按需 | 独立封面／模块文件 | 继续制作或导出 |

没有图像或排版能力的宿主只能交付方案和提示词，应明确说明没有实际生成预览。已经认可预览或只需要提示词时，无需重复确认。
